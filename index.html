Protéticos / laboratórios

Defina quais laboratórios estão disponíveis. Aditivo significa que a clínica paga o laboratório e o dentista recebe +50% do valor. Subtrativo significa que o dentista paga o laboratório e recebe -50% desse valor.

Excluir lançamentos

Apaga os lançamentos financeiros e de protético deste aparelho. Título, foto, cor e taxas permanecem intactos.

Esta ação não pode ser desfeita. Recomendamos fazer um backup antes.

Backup dos dados

Use o backup para levar seus lançamentos, perfil e configurações para outro aparelho. Também é possível importar uma base de dados sem substituir sua personalização atual.

Backup manual: nunca · Backup automático local: aguardando dados
Além do backup manual em JSON, o aplicativo mantém até 3 estados automáticos localmente neste aparelho. Eles ajudam a recuperar um estado anterior após uma exclusão ou alteração acidental, mas não substituem guardar o JSON fora do aparelho.

Limpar aplicativo

Apaga lançamentos, título, foto, taxas, cor personalizada e dados locais deste aparelho. O aplicativo volta ao estado inicial.

Esta ação é permanente neste aparelho. Faça um backup antes de usar, caso queira guardar os lançamentos.
Os dados ficam armazenados localmente neste navegador. Backup e configurações ficam disponíveis no menu ⚙.
